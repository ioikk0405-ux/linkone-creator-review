LinkONE · TikTok Creator Review 2.0.1
데스크톱 Chrome용

미리 보기
ZIP을 먼저 압축 해제한 뒤 ‘미리보기.html’을 Chrome으로 열어주세요. 실제 계정에 접속하지 않고 가상 프로필로 캠페인 전환, 지표, 게시물 직접 추가, 요약·CSV를 확인할 수 있습니다. 예시에서 링크 2개를 채우고 목록에 추가하면 관련 게시물이 3건에서 4건으로 늘어납니다. 하나는 자동 결과와 겹칩니다.

설치
Chrome 주소창에 chrome://extensions 를 입력합니다. ‘개발자 모드 → 압축해제된 확장 프로그램을 로드합니다’에서 ZIP 안의 LinkOne-TikTok-2.0.1 폴더를 선택합니다. 인스타 버전과 함께 쓸 수 있습니다. 틱톡 0.1 버전을 이미 사용 중이라면 기존 설치 폴더에 새 확장 파일을 덮어쓰고 해당 카드의 새로고침을 눌러주세요. 별도 폴더로 설치했다면 이전 틱톡 확장은 꺼주세요. 틱톡 프로필 탭도 새로고침합니다.

기존 버전을 업데이트하려면 기존에 Chrome에 등록한 폴더 안의 파일을 2.0.1 폴더 내용으로 덮어쓴 뒤 확장 카드의 새로고침을 누르고 틱톡 탭을 새로고침합니다.

계정 검토
1. PC에서 www.tiktok.com/@아이디 형식의 프로필을 열고 게시물 탭을 조금 내립니다. 오른쪽 아래 패널에서 ‘매장 홍보’ 또는 ‘제품 홍보’를 선택합니다.
2. 분야는 뷰티·리빙·건강식품입니다. ‘전체’에서는 분야 제한 없이 검토합니다. 분야를 여러 개 고르면 그중 하나가 맞으면 됩니다. 키워드도 입력하면 분야와 키워드가 모두 맞는 글을 보여줍니다. 타깃·지역은 GPT 검토 요청에 들어갑니다.
3. 게시 기간은 전체·최근 7일·최근 1개월(30일)·최근 90일·직접 설정입니다. 한국시간 게시일을 기준으로 양 끝 날짜를 포함합니다. 게시일 미확인 글은 전체에서만 집계하며, 기간별 수치는 그 기간에 올라온 글의 현재 누적 반응입니다.
4. 프로필을 새로고침하고 목록을 조금 내리면 틱톡이 불러온 게시물 목록의 공개 수치와 게시일을 같은 계정·게시물 번호의 카드에 연결합니다. 원문 정보가 필요하면 ‘게시물 정보 불러오기’를 누릅니다. 확인된 링크를 순서대로 읽으며 다시 누르면 중단합니다. 처음 최대 6건, 수동 요청당 최대 24건이며 접근 제한·로그인 요청 시 중단합니다. 직접 연 게시물도 작성자와 게시물 번호가 확인된 공개 정보만 반영합니다. 프로필 계정과 원문이 일치하는지 확인합니다.
5. ‘관련 게시물’에서 자동으로 찾은 표현과 확인 후보를 봅니다. 게시물 번호·캡션·썸네일 설명으로 원문을 추적합니다. 영상 속 장면, 자막, 음성은 자동 분석하지 않습니다.

게시물 직접 추가
현재 계정의 틱톡 원문을 열어 주소창에서 https://www.tiktok.com/@아이디/video/번호 또는 /photo/번호 주소를 복사합니다. ‘관련 게시물 → 게시물 직접 추가’에 한 줄에 하나씩 넣습니다. 모바일 단축 공유 링크는 먼저 열어서 원문 주소로 바꿔주세요.
매장·제품 홍보 각각 10개까지 저장하며 같은 게시물 번호는 한 번만 집계합니다. 검색어와 맞지 않아도 직접 선정한 글은 검토 대상입니다. ‘입력·수정’에서 게시일, 원문에서 그대로 옮긴 캡션, 선정 이유를 구분해 기록할 수 있습니다. 기간 밖의 글도 직접 추가 목록에서 수정·삭제할 수 있습니다. 직접 선정한 글은 관련 게시물 지표에 포함되며, 확인된 공개 수치만 중앙값에 반영합니다.
직접 선정 목록과 캠페인 조건은 이 Chrome에 저장됩니다. 자동 표본은 최대 8계정, 계정당 100건이며 최근 12시간 이내에 읽은 값을 재사용합니다. 계정 전체 게시물을 일괄 수집하지 않습니다.

틱톡 지표
• 영상 조회수와 게시물 좋아요·댓글·공유·저장을 각각 중앙값으로 표시합니다. 게시물별 원문과 공개 반응을 펼치면 새로 읽은 공유·저장의 출처를 확인할 수 있습니다. 영상·사진을 구분하며 조회수 기준의 지표에는 영상만 포함합니다.
• 조회수 대비 영상 반응률은 각 영상의 (좋아요 + 댓글 + 공유) ÷ 조회수 × 100을 구한 뒤 중앙값을 표시합니다. 세 반응 수치가 모두 확인되고 조회수가 1회 이상인 영상만 계산합니다. 저장은 별도 지표로 봅니다.
• 팔로워 대비 게시물 반응률은 인스타 1.7과 같은 방식으로 각 게시물의 (좋아요 + 댓글) ÷ 현재 팔로워 수 × 100을 계산한 중앙값입니다.
• 협찬 표기 확인·미확인 영상의 조회수도 나누어 봅니다. 표기 미확인은 협찬 여부를 알 수 없다는 뜻입니다. 공개 수치가 0이면 집계하고 빈 수치는 미확인으로 남깁니다. K·M·만 등 축약 표기는 근삿값입니다.
• 팔로워 연령·거주지, 영상 시청 유지율, 매장 방문·시딩 구매 실적은 별도 자료가 필요합니다. 조회수는 순시청자 수와 다를 수 있습니다.

팀 공유 / GPT 검토
‘요약 복사’와 ‘CSV 다운로드’에 선택 조건과 기간이 반영됩니다. ‘적합도’에서 제품·매장·브랜드 등 검토 대상을 입력하고 ‘적합도 검토 요청문 복사’를 눌러 ChatGPT나 Claude에 붙여넣습니다. 요청문에는 원문 링크, 확인 수치·표본 범위, 타깃이 포함됩니다. 직접 선정한 글을 우선해 최대 24건을 전달합니다. 수기로 적은 선정 이유는 담당자 메모로 구분됩니다.
‘적합도 → 섭외 판단 기준’에서 추천·보통·비추천 기준을 확인할 수 있습니다. 판단할 원문이 없으면 등급은 보류합니다. 요청문과 패널 검토에 같은 기준이 적용됩니다.
기존 PC 도우미를 사용하는 경우 실행 중인 도우미를 종료하고 이 ZIP의 GPT-도우미를 실행해 새 연결 코드를 등록합니다.
패널 안에서 바로 GPT를 사용하려면 Python 3.9 이상이 있는 PC에서 ‘GPT-도우미/start-windows.cmd’ 또는 ‘python3 assistant.py’를 실행합니다. 본인 OpenAI API 키를 도우미에 입력하고 발급된 연결 코드를 패널 상단 설정에서 등록합니다. 틱톡 전용 도우미는 포트 41868을 사용합니다. ‘연결한 GPT로 적합도 검토’를 눌러야 선택한 계정 지표·캠페인·공개 게시물 발췌·입력한 메모가 전송되며 API 요금이 발생할 수 있습니다. 적합도 검토 요청문 복사는 연결 없이 사용할 수 있습니다.

분야별 계정 지표
상단에서 선택한 분야와 게시 기간에 맞는 게시물로 지표를 계산합니다. 여러 분야를 선택하면 중복된 게시물은 한 번만 집계합니다. 전체에는 분야 미확인 게시물도 포함합니다. 건강식품에는 단백질·식사대용, 비타민·미네랄, 유산균, 유기농 먹거리 등이 포함됩니다. 기존 식품 선택은 건강식품으로 연결됩니다.
화면에만 제품명이 보이면 ‘게시물 직접 추가 → 입력·수정’의 화면 문구에 그대로 옮깁니다. 실제로 읽은 게시물과 같은 링크이면 분야 판별에 반영되며 링크만 추가한 글은 관련 지표의 대상 건수에 포함되지만 확인된 수치가 없으면 중앙값 계산에서 제외됩니다.

리빙은 주방·식기, 욕실·청소·세탁, 수납, 가구·침구·조명, 생활가전 등의 한글·영문 품목명을 확인합니다. 제품명만 확인한 글은 원문 확인 후보에 포함합니다.

2.0.1 추가 기능
• 계정 지표 탭에서 ‘읽은 전체/선택 분야 전체’와 ‘관련 게시물’을 전환합니다. 관련 지표는 관련 게시물 탭의 표현 확인·확인 후보·직접 선정 글을 중복 없이 집계합니다. 직접 선정 글은 분야·키워드와 달라도 해당 게시 기간에 맞으면 포함됩니다. 원문을 확인하지 못한 직접 선정 글도 대상 건수에는 포함되지만, 없는 수치는 집계하지 않습니다.
• 각 지표는 확인 건수/대상 건수를 표시합니다. 게시 기간 기준으로 선택된 글의 현재 누적 수치이며 해당 기간의 증가량이 아닙니다. 두 표본은 겹칠 수 있으므로 독립된 비교군이 아닙니다. 관련 게시물이 5건 미만이면 적은 표본임을 안내합니다. 5건 이상이라고 신뢰도가 확보되는 것은 아닙니다.
• 요약 복사에는 두 범위의 지표가 포함됩니다. 계정 지표 탭의 CSV는 현재 선택한 범위의 게시물만 내보냅니다.
• 적합도 탭에서 제품명·유형, 매장명·위치, 브랜드명과 특징을 입력하면 각각 검토합니다. 입력은 관련 게시물 검색 필터를 바꾸지 않습니다. 분야·키워드·홍보 방식을 조절하거나 수기로 원문을 추가해 검토 표본을 구성하세요.
• 브랜드 적합도는 콘텐츠와 입력한 브랜드 방향의 연결을 검토합니다. 실제 소비자의 브랜드 반응·댓글 감성·팔로워 연령과 거주지·방문·구매 실적은 추정하지 않습니다.
• 대상을 입력하고 요청문만 복사하면 API가 호출되지 않습니다. ‘연결한 GPT로 적합도 검토’를 누를 때 세 대상을 한 번의 요청으로 검토합니다. 자동 유료 분석은 없습니다. 새 결과에는 원문 인용 검증을 적용합니다.
• 기존 도우미를 사용했다면 창을 종료하고 이번 ZIP의 GPT-도우미 폴더로 교체해 실행합니다. 인스타와 틱톡 도우미는 각각 다른 포트를 사용하므로 동시에 사용할 수 있습니다.


2.0.1 안정화
- 입력한 제품·매장·브랜드의 표현을 선택 기간의 읽은 원문에서 우선 선정합니다. 미입력 시 기존 분야·키워드 기준을 사용합니다. 텍스트가 없는 수기 링크는 목록에 남지만 GPT 근거로 보내지 않습니다.
- 적합도 표본은 최대 24건이며 검토·미포함·원문 미확인 건수를 표시합니다. 키워드나 표현을 찾지 못한 자료와 발췌에서 빠진 맥락은 담당자가 직접 선정하여 보완할 수 있습니다. 게시물 전체를 자동 수집하거나 영상 장면을 판독하지 않습니다.
- 필수조건은 쉼표·세미콜론으로 구분합니다. 확인·미확인·충돌을 원문과 함께 표시합니다. 이번 촬영 가능성·일정·실제 고객층·성과 등 외부 증빙이 필요한 조건은 공개 게시물만으로 확인 처리하지 않습니다. 미확인 조건이 있으면 추천을 보류합니다.
- 조건 판단과 콘텐츠의 의미 해석은 AI 검토입니다. 인용이 원문에 존재한다는 검사는 의미 판단의 정확성을 보증하지 않습니다. 섭외 전 원문과 필요한 증빙을 확인하세요.
- 원문 없는 분석과 중복 실행을 차단합니다. 검토 중 조건이 바뀌면 이전 결과를 표시하지 않으며 자동 재호출하지 않습니다. 같은 자료의 갱신은 결과를 지우지 않습니다.
- 기존 PC 도우미를 종료하고 이 ZIP의 도우미를 실행한 뒤 새 연결 코드를 등록하세요. 이전 도우미는 연결 단계에서 안내합니다.
- 기존 계정·관련 게시물 지표, 날짜·분야·키워드 필터, 직접 추가, CSV·요청문 복사 기능은 유지합니다.

검증 범위
가상 데이터와 API 모의 응답으로 집계·선정·근거 검증·화면 동작·연결 절차를 점검했습니다. 실제 Instagram/TikTok 화면에서의 수집과 실제 모델 응답은 사용자 환경에서 추가 확인이 필요합니다. 유료 API 검증은 실행하지 않았습니다.
