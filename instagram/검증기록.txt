LinkOne 2.0.1 안정화 검증 기록 · 2026-11-19

운영 원칙
신규 기능 확대보다 현재 인스타그램·틱톡 기능의 완성도를 우선합니다. 실제 사용에서 확인되지 않은 부분을 완료로 표시하지 않습니다.

이번 수정
1. 선택 기간의 읽은 원문에서 입력 제품·매장·브랜드별 표현을 우선 선정하고, 최대 24건 안에서 중복을 제거합니다. 관련 게시물 목록과 계정 지표의 집계 기준은 유지합니다.
2. 긴 글은 대상 표현 주변을 발췌합니다. 검토·미포함·원문 미확인 건수를 표시합니다.
3. 필수조건별 확인·미확인·충돌과 원문을 표시합니다. 이번 촬영 가능성·일정·고객층·성과 등 외부 증빙이 필요한 조건은 공개 게시물만으로 확인 처리하지 않습니다. 미확인 조건이 있으면 추천을 제한합니다.
4. 원문 없는 요청과 중복 실행을 막습니다. 검토 중 조건이 바뀌면 이전 결과를 버리되 유료 요청을 자동으로 다시 보내지 않습니다. 같은 자료의 시간 갱신만으로 결과가 지워지지 않습니다.
5. 이전 PC 도우미를 연결하면 업데이트 안내를 표시합니다. 로고와 설정 파일 참조를 확인했습니다.

확인 완료 · 가상 데이터/모의 응답 기준
- 인스타·틱톡 기존 검사 각각 336건 통과: 카테고리, 날짜, 키워드, 지표, 원문 링크, 수기 추가, 화면 이벤트 등.
- 계정 전환, 캐시, 접근 제한 시 중단, 원문 작성자 확인 흐름 통과.
- TikTok 공개 응답: 동일 게시물 연결, 저장/공유 구분, 미확인과 실제 0 구분 통과.
- 30건 뒤쪽의 브랜드 원문 선정, 한글 제품 입력과 영문 표현, 긴 글의 대상 표현 유지, 기간 밖/날짜 미확인 제외, 수기 10건 우선 선정 통과.
- 대상 입력에 따른 분석 표본 변경, 관련 지표 범위 유지, 원문 없는 요청 차단 통과.
- 조건 결과 누락·중복·거짓 인용 차단, 현장 촬영 증빙 없는 추천 제한, 명시적 충돌 처리 통과.
- 연속 클릭, 분석 중 조건 변경, 동일 자료 갱신, 같은 객체의 내용 변경 반영 통과.
- 로컬 HTTP 연결 코드 인증, 출처 검사, 신규 분석 경로 검증 통과. 모델 응답은 모의 응답이며 실제 유료 API를 호출하지 않았습니다.
- ZIP 내부 코드와 현재 소스 일치, 버전 2.0.1, 참조 파일, 아이콘, Windows 실행 파일 줄바꿈 점검.

추가 확인 필요
- 실제 Instagram/TikTok 화면의 게시물·날짜·반응 수집 결과와 원문 대조.
- 실제 모델의 제품·매장·브랜드 및 필수조건 의미 판단 품질.
- 사용자 Chrome/Windows에서 패널 표시와 설치·도우미 실행. 이 환경의 Chromium 실행이 실패하여 실제 브라우저 렌더링 검증은 완료하지 못했습니다.

해석상 한계
읽어온 공개 텍스트와 지표의 분석입니다. 모든 게시물·영상 장면·댓글 본문을 자동으로 확보하지 않습니다. 표현 기반 선정과 인용 검증은 의미 판단의 정확성을 보증하지 않습니다. 실제 팔로워 연령·거주지와 방문·구매 실적은 추정하지 않으며 필요한 증빙은 별도 확인합니다.
