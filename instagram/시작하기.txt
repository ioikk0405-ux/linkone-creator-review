LinkOne | 인스타그램 크리에이터 검토
데스크톱 Chrome용 · 2.0.2

2.0.2에서 달라진 점
• 필수조건은 한 줄에 하나씩 적습니다. ‘뉴욕, 뉴저지 거주’처럼 쉼표가 들어간 문장은 한 조건입니다. 예전에 한 줄에 쉼표로 여러 조건을 적어 두었다면, 줄을 나눠 다시 입력하세요.
• ‘팔로워 1만 이상’, ‘followers 10k+’ 같은 숫자 조건은 패널이 읽은 팔로워 수로 판단합니다. 팔로워 수를 모르면 미확인으로 남고, 미확인 조건이 있으면 추천하지 않습니다.
• 인용 문장의 마침표나 띄어쓰기가 조금만 달라도 검토 결과 전체가 오류로 사라지지 않습니다. 맞지 않는 인용만 빠지거나, 그 조건만 미확인으로 남습니다.
• 확장과 PC 도우미를 함께 2.0.2로 바꿔야 합니다. 패널 상단의 Creator Review 2.0.2로 적용 여부를 확인합니다. 폴더 이름은 LinkOne-Extension-2.0.1 그대로입니다.

기존 설치본 업데이트
압축을 풀고 새 ‘LinkOne-Extension-2.0.1’ 폴더 안의 파일을 기존에 크롬으로 불러온 확장프로그램 폴더 안에 덮어씁니다. chrome://extensions에서 LinkOne 카드의 새로고침(↻)을 누른 뒤 열어둔 인스타 탭에서 F5를 누릅니다. 패널 상단의 Creator Review 2.0.2 표시로 적용 여부를 확인합니다.

먼저 보기
미리보기.html을 Chrome에서 열면 가상 계정의 게시물 8건으로 패널을 조작할 수 있습니다. 처음에는 ‘매장 홍보 / 전체’가 선택되어 있습니다. ‘제품 홍보’를 누르고 ‘전체 → 건강식품’을 선택하면 비타민 젤리 시식 게시물이 남습니다. 원문 카드를 누르면 예시 캡션을 확인할 수 있습니다. 예시 수치는 실제 인물의 지표가 아닙니다.

실제 계정에서 사용
1. ZIP 파일을 먼저 압축 해제합니다.
2. 데스크톱 Chrome 주소창에 chrome://extensions 를 입력합니다.
3. 오른쪽 위 ‘개발자 모드’를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’를 누릅니다.
4. manifest.json이 직접 들어 있는 ‘LinkOne-Extension-2.0.1’ 폴더를 선택합니다. 설치 후 폴더를 이동하면 다시 불러와야 합니다.
5. Instagram에서 sickovivian 프로필을 열거나 새로고침합니다. 오른쪽 아래에 검토 패널이 표시됩니다. 게시물·릴스 탭에서 화면을 조금 내리면 읽을 수 있는 게시물이 추가됩니다. 실계정 열람은 사용 중인 Chrome의 Instagram 접근 상태에 따릅니다. 이 확장은 계정 로그인이나 DM·좋아요·팔로우를 수행하지 않습니다.
6. 패널의 ‘계정 지표’에서 ‘이 계정의 릴스 탭 열기’를 누르고 목록을 조금 내립니다. 표시된 릴스의 조회수가 화면과 일치하는지 ‘계정 지표 → 게시물별 원본과 조회수’에서 확인합니다. 겹치는 다른 패널이 있으면 잠시 접어주세요.

캠페인 조건
• 매장 홍보는 매장 투어와 방문 안내를 찾습니다. 장소만 언급한 글은 원문 확인 후보에 표시됩니다.
• 제품 홍보는 시식·사용·언박싱·발색·리뷰 등 경험을 적은 표현을 찾습니다.
• 분야는 뷰티, 리빙, 건강식품입니다. 이전에 선택한 패션·팝·문화는 해제됩니다. 다른 분야를 함께 선택했다면 그 분야만 남습니다. 행사·굿즈는 ‘전체’에서 행사명이나 포토카드 등으로 검색할 수 있습니다.
• 분야는 복수 선택할 수 있습니다. 선택한 분야 중 하나와 홍보 대상이 함께 맞아야 근거로 표시됩니다. ‘전체’는 분야 제한을 해제합니다. 분야에 없는 상품은 ‘전체’에서 게시물 검색 키워드를 입력합니다.
• 게시물 검색 키워드는 캡션과 썸네일 설명에서 찾습니다. 쉼표로 나눈 키워드 중 하나가 맞으면 통과합니다. 분야도 선택했다면 해당 분야의 표현도 있어야 합니다. ‘광동’과 ‘Kwangdong’ 등 등록한 동의어를 함께 찾습니다. 키워드를 입력하면 자동 검색 결과 중 일치한 글과 직접 선정한 글을 GPT에 전달합니다. 검색 결과가 0건이면 글을 직접 선정하거나 검색어를 바꾸거나 게시물 정보를 추가로 불러올 수 있습니다.
• 타깃·지역은 GPT가 협업 의견을 작성할 때 참고합니다. 복사한 검토 요청문과 직접 연결한 GPT 요청 양쪽에 포함됩니다. 이 값을 바꿔도 게시물 목록과 계정 지표는 같습니다. 실제 팔로워 연령·지역은 별도 자료로 확인해야 합니다.

게시물 직접 추가
• ‘관련 게시물 → 게시물 직접 추가’에서 현재 계정의 피드·릴스 원문 링크를 한 줄에 하나씩 붙여넣고 ‘목록에 추가’를 누릅니다. 매장 홍보와 제품 홍보에 각각 10건을 저장할 수 있습니다. 같은 글을 다시 넣거나 자동 결과와 겹쳐도 관련 게시물 수는 한 번만 증가합니다. 추적 파라미터가 달라도 같은 글로 처리합니다.
• 직접 선정한 글은 분야·키워드가 일치하지 않아도 관련 게시물, GPT 검토, 요약, CSV에 포함됩니다. 선택한 기간에는 게시일이 확인된 글만 포함되며, 기간 밖이거나 게시일이 없는 글도 직접 추가 목록에서 계속 관리할 수 있습니다.
• ‘게시물 정보 불러오기’로 공개 원문을 확인합니다. 원문을 읽지 못하면 ‘입력·수정’에서 게시일·원문 그대로의 캡션·선정 이유를 따로 적을 수 있습니다. 선정 메모는 담당자 의견으로 표시됩니다. 원문 링크만 있어도 저장할 수 있습니다. 작성자가 다른 계정으로 확인되면 검토 건수에서 제외합니다.
• 직접 입력한 링크만으로 계정 지표의 표본을 늘리지 않습니다. 목록은 현재 Chrome에 계정·홍보 유형별로 저장되며 각 글의 ‘삭제’로 뺄 수 있습니다. 미리보기에서는 예시 링크를 채워 테스트할 수 있고 파일을 다시 열면 초기화됩니다.

판단 근거와 지표
• 콘텐츠 근거의 전체 건수에는 홍보 경험 표현이 있는 게시물과 분야·키워드만 맞는 원문 확인 후보가 포함됩니다. 직접 선정한 글까지 합쳐 중복 없이 집계합니다. 각 카드에 표현을 찾은 출처를 표시합니다. 이미지 속 글자의 OCR은 지원하지 않습니다.
• 팔로워 대비 게시물 반응률은 (게시물 좋아요 + 댓글) ÷ 현재 팔로워 수 × 100을 각 게시물에 적용한 뒤 계산한 중앙값입니다. 매장·제품을 전환해도 계정 지표의 대상은 선택 기간에 읽은 동일한 게시물입니다. 지금 선택한 기간에서 좋아요와 댓글이 모두 확인된 게시물만 포함합니다. 팔로워 수가 없거나 0이면 참여율을 계산하지 않습니다. 팔로워 수는 계정과 일치하는 상단 표기 또는 공개 프로필 설명에서 읽고, 실패하면 ‘계정 지표 → 프로필에서 본 팔로워 수 직접 입력’으로 입력할 수 있습니다. 직접 입력은 해당 계정에만 적용됩니다. 공개 팔로워 수를 읽으면 자동값을 우선합니다.
• 콘텐츠 근거는 캡션 또는 썸네일 설명과 원문 링크를 연결합니다. 문맥이 맞는지 원문에서 확인합니다. 지역과 카테고리가 맞더라도 방문·구매 성과를 예측하지 않습니다.
• 공개 릴스 표기가 있으면 화면 숫자를 우선합니다. ‘1.2만’처럼 축약된 숫자는 근삿값입니다. 명확한 원문 재생 수치만 있는 경우 그 수치를 사용합니다. 0회는 포함하고 숨겨진 값과 미확인은 중앙값에서 제외합니다.
• ‘협찬 표기’는 유료 파트너십 정보나 캡션 등의 광고·제공 표기에서 확인합니다. ‘표기 미확인’은 광고 여부 미상입니다.
• 공개 목록을 계정 안에서 중복 제외해 최대 100건 저장합니다. 처음 최대 6건, ‘게시물 정보 불러오기’를 누르면 한 번에 최대 24건의 원문을 순서대로 확인합니다. 접근 제한 시 중단합니다. ‘게시 기간’에서 전체, 최근 7일, 최근 1개월(30일), 최근 90일, 직접 설정을 선택합니다. 최근 기간은 한국시간 오늘을 포함하며, 직접 설정은 시작일과 종료일 양쪽을 포함합니다. 기간은 게시일 기준입니다. 선택 기간에 게시된 글의 현재 반응 수치를 집계합니다. 게시일을 확인하지 못한 글은 전체에서만 포함하며, 기간을 선택하면 제외 건수를 표시합니다. 관련 게시물, 계정 지표, GPT 요청문, 요약, CSV에 같은 기간이 적용됩니다.
• 콘텐츠와 계정 지표는 수집한 표본에 한합니다. 지역별 시청자, 저장·공유, 매장 방문, 구매 실적은 제공하지 않습니다. 한국어·영어 문구 기반이라 간접 표현이나 영상 속에만 나오는 장면은 놓칠 수 있습니다.
• 조건은 이 Chrome에 저장됩니다. 최근 표본은 최대 8계정, 재사용 기한 12시간입니다. ‘요약 복사’와 ‘CSV 다운로드’로 개별 원문과 판단 근거를 팀에 공유할 수 있습니다.

적합도 검토
‘적합도’에서 제품명·유형, 매장명·위치, 브랜드명과 특징 중 검토할 대상을 입력합니다. 홍보 목적과 필수조건도 함께 적습니다. 입력한 대상별로 추천·보통·비추천·판단 보류, 원문 인용과 링크, 부족한 자료를 나눠 검토합니다. 대상 입력은 게시물 검색 조건에 영향을 주지 않습니다.
‘적합도 검토 요청문 복사’ 후 ChatGPT나 Claude에 붙여넣으면 별도 API 연동 없이 검토할 수 있습니다. 패널 안에 결과를 표시하려면 선택 기능인 PC 도우미를 사용합니다.

선택 기능 | 패널 안에서 적합도 받기
PC에 Python 3.9 이상과 본인의 OpenAI API 키가 있을 때 사용할 수 있습니다. API 비용은 해당 키의 계정에 발생할 수 있습니다.
기존 도우미를 쓰고 있다면 창을 종료하고 새 ZIP의 GPT-도우미 폴더 전체를 교체한 후 다시 실행합니다.
1. Windows는 GPT-도우미/start-windows.cmd를, 다른 OS는 터미널에서 python3 assistant.py를 실행합니다.
2. 도우미 창에 API 키를 입력합니다. OPENAI_API_KEY 환경변수도 지원합니다.
3. 도우미가 표시한 ‘연결 코드’를 패널 오른쪽 위 설정에 입력하고 ‘연결 확인’을 누릅니다. API 키는 확장 설정에 입력하지 않습니다.
4. 적합도에서 ‘연결한 GPT로 적합도 검토’를 누를 때만 캠페인 조건·타깃 및 게시물 최대 24건의 설명과 지표를 OpenAI로 전송합니다. 결과가 제공된 게시물을 인용했는지 검사합니다.
5. 도우미를 다시 시작하면 새 코드로 연결합니다. 종료는 Ctrl+C입니다. 브라우저를 재시작하면 연결 코드를 다시 입력합니다.

게시물이 0건인 경우
프로필의 게시물·릴스 탭을 열었는지, 본인 브라우저에서 원문이 열리는지 확인합니다. 일부 화면에서는 Instagram이 공개하지 않는 캡션·조회수를 읽을 수 없습니다. 이때 패널은 수치를 추정하지 않고 ‘미확인’으로 표시합니다.

분야별 계정 지표
상단에서 선택한 분야와 게시 기간에 맞는 게시물로 지표를 계산합니다. 여러 분야를 선택하면 중복된 게시물은 한 번만 집계합니다. 전체에는 분야 미확인 게시물도 포함합니다. 건강식품에는 단백질·식사대용, 비타민·미네랄, 유산균, 유기농 먹거리 등이 포함됩니다. 기존 식품 선택은 건강식품으로 연결됩니다.
화면에만 제품명이 보이면 ‘게시물 직접 추가 → 입력·수정’의 화면 문구에 그대로 옮깁니다. 실제로 읽은 게시물과 같은 링크이면 분야 판별에 반영되며 링크만 추가한 글은 관련 지표의 대상 건수에 포함되지만 확인된 수치가 없으면 중앙값 계산에서 제외됩니다.

리빙은 주방·식기, 욕실·청소·세탁, 수납, 가구·침구·조명, 생활가전 등의 한글·영문 품목명을 확인합니다. 제품명만 확인한 글은 원문 확인 후보에 포함합니다.

2.0.1 추가 기능
• 계정 지표 탭에서 ‘읽은 전체/선택 분야 전체’와 ‘관련 게시물’을 전환합니다. 관련 지표는 관련 게시물 탭의 표현 확인·확인 후보·직접 선정 글을 중복 없이 집계합니다. 직접 선정 글은 분야·키워드와 달라도 해당 게시 기간에 맞으면 포함됩니다. 원문을 확인하지 못한 직접 선정 글도 대상 건수에는 포함되지만, 없는 수치는 집계하지 않습니다.
• 각 지표는 확인 건수/대상 건수를 표시합니다. 게시 기간 기준으로 선택된 글의 현재 누적 수치이며 해당 기간의 증가량이 아닙니다. 두 표본은 겹칠 수 있으므로 독립된 비교군이 아닙니다. 관련 게시물이 5건 미만이면 적은 표본임을 안내합니다. 5건 이상이라고 신뢰도가 확보되는 것은 아닙니다.
• 요약 복사에는 두 범위의 지표가 포함됩니다. 계정 지표 탭의 CSV는 현재 선택한 범위의 게시물만 내보냅니다.
• 적합도 탭에서 제품명·유형, 매장명·위치, 브랜드명과 특징을 입력하면 각각 검토합니다. 입력은 관련 게시물 검색 필터를 바꾸지 않습니다. 분야·키워드·홍보 방식을 조절하거나 수기로 원문을 추가해 검토 표본을 구성하세요.
• 브랜드 적합도는 콘텐츠와 입력한 브랜드 방향의 연결을 검토합니다. 실제 소비자의 브랜드 반응·댓글 감성·팔로워 연령과 거주지·방문·구매 실적은 추정하지 않습니다.
• 대상을 입력하고 요청문만 복사하면 API가 호출되지 않습니다. ‘연결한 GPT로 적합도 검토’를 누를 때 세 대상을 한 번의 요청으로 검토합니다. 자동 유료 분석은 없습니다. 새 결과에는 원문 인용 검증을 적용합니다.
• 기존 도우미를 사용했다면 창을 종료하고 이번 ZIP의 GPT-도우미 폴더로 교체해 실행합니다. 인스타와 틱톡 도우미는 각각 다른 포트를 사용하므로 동시에 사용할 수 있습니다.


2.0.1 안정화
- 입력한 제품·매장·브랜드의 표현을 선택 기간의 읽은 원문에서 우선 선정합니다. 미입력 시 기존 분야·키워드 기준을 사용합니다. 텍스트가 없는 수기 링크는 목록에 남지만 GPT 근거로 보내지 않습니다.
- 적합도 표본은 최대 24건이며 검토·미포함·원문 미확인 건수를 표시합니다. 키워드나 표현을 찾지 못한 자료와 발췌에서 빠진 맥락은 담당자가 직접 선정하여 보완할 수 있습니다. 게시물 전체를 자동 수집하거나 영상 장면을 판독하지 않습니다.
- 필수조건은 한 줄에 하나씩 입력합니다. 줄 안의 쉼표는 조건 내용으로 남습니다. 확인·미확인·충돌을 원문과 함께 표시합니다. 팔로워 수 기준은 확인된 팔로워 수로 판단하고, 수가 없으면 미확인입니다. 이번 촬영 가능성·일정·실제 고객층·성과 등 외부 증빙이 필요한 조건은 공개 게시물만으로 확인 처리하지 않습니다. 미확인 조건이 있으면 추천을 보류합니다.
- 조건 판단과 콘텐츠의 의미 해석은 AI 검토입니다. 인용이 원문에 존재한다는 검사는 의미 판단의 정확성을 보증하지 않습니다. 섭외 전 원문과 필요한 증빙을 확인하세요.
- 원문 없는 분석과 중복 실행을 차단합니다. 검토 중 조건이 바뀌면 이전 결과를 표시하지 않으며 자동 재호출하지 않습니다. 같은 자료의 갱신은 결과를 지우지 않습니다.
- 기존 PC 도우미를 종료하고 이 ZIP의 도우미를 실행한 뒤 새 연결 코드를 등록하세요. 이전 도우미는 연결 단계에서 안내합니다.
- 기존 계정·관련 게시물 지표, 날짜·분야·키워드 필터, 직접 추가, CSV·요청문 복사 기능은 유지합니다.

검증 범위
가상 데이터와 API 모의 응답으로 집계·선정·근거 검증·화면 동작·연결 절차를 점검했습니다. 실제 Instagram/TikTok 화면에서의 수집과 실제 모델 응답은 사용자 환경에서 추가 확인이 필요합니다. 유료 API 검증은 실행하지 않았습니다.
